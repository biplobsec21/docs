Type: Anton (headlines, stands in for Airtasker's PP Formula) + Manrope (UI, same as Airtasker) + Hind Siliguri (Bangla). Pill buttons, 16–24 px radius, navy footer card.

Assumptions shown in the mock

  • Commission 17% + 15% VAT on commission (D28, D29 not final)
  • Payment method chosen when accepting an offer (D11) · 15-minute payment timeout
  • Bidding window 2 / 6 / 24 / 48 h (D12) · counter offers up to 3 rounds
  • 48 h to approve, then auto-release (D14) · arrival by GPS + 4-digit code (D17)
  • Public Q&A on tasks with phone numbers/links masked (new idea from Airtasker — not in the spec yet)
  • Hotline number is a placeholder (D42)
